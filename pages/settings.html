About MoneyFlow

Version 1.0.0

A production-grade personal finance manager. All data lives exclusively in your browser's localStorage — nothing is sent to any server.

Built with HTML5, CSS3, Vanilla JS ES6+ and Chart.js.

Chart.js 4.4 localStorage Web Crypto API WCAG AA
